# Buttons

**Default:** Primary, Medium.

## Icon

-	**Text Only**
	```html
	<button>Label</button>
	```
-	**Icon & Text**
	```html
	<button>
		<span class="material-symbols-outlined">icon_name</span>
		Label
	</button>
	```
-	**Icon Only**
	```html
	<button class="icon">
		<span class="material-symbols-outlined">icon_name</span>
	</button>
	```

## Types

-	**Primary** (default)
	```html
	<button>...</button>
	```

	or

	```html
	<button class="primary">...</button>
	```
-	**Secondary**
	```html
	<button class="secondary">...</button>
	```

## Sizes

-	**Small**
	```html
	<button class="small">...</button>
	```
-	**Medium** (default)
	```html
	<button>...</button>
	```
-	**Large**
	```html
	<button class="large">...</button>
	```

# Button Groups

```html
<div class="button-group" role="group">
	<button><span class="material-symbols-outlined">icon</span> Label</button>
	...
</div>
```

# Tabs and Panels

The tabs part:

```html
<div class="tabs" id="tabs" role="tablist">
	<button class="tab tab-active" id="first-tab" aria-controls="first-panel" aria-selected="true" role="tab" tabindex="0">Tab 1</button>
	<button class="tab" id="second-tab" aria-controls="second-panel" aria-selected="false" role="tab" tabindex="1">Tab 2</button>
</div>
```

The panel part:

```html
<section class="panel" id="first-panel" role="tabpanel" aria-labelledby="first-tab"></section>
<section class="panel" id="second-panel" role="tabpanel" aria-labelledby="second-tab" hidden></section>
```

Attributes for tabs:

| Attribute       | Active             | Inactive  |
| --------------- | ------------------ | --------- |
| `aria-selected` | `"true"`           | `"false"` |
| `class`         | `"tab tab-active"` | `"tab"`   |

Attributes for panels:

| Attribute | Active | Inactive |
| --------- | ------ | -------- |
| `hidden`  | ✗      | ✓        |

These attributes must match:

| Tab             | Panel             |
| --------------- | ----------------- |
| `id`            | `aria-labelledby` |
| `aria-controls` | `id`              |

# Chips

## Toggle

-	**Enabled** (default)
	```html
	<label class="chip">
		<input type="checkbox" hidden />
		<span>...</span>
	</label>
	```
-	**Disabled**
	```html
	<label class="chip">
		<input type="checkbox" hidden disabled />
		<span>...</span>
	</label>
	```

## Info

```html
<label class="chip">Label</label>
```

# Headings

-	**Text Only**
	```html
	<h1>Heading</h1>
	```
-	**With Icon**
	```html
	<h1>
		<span class="material-symbols-outlined">icon_name</span>
		Heading
	</h1>
	```
-	**With Link**
	```html
	<h1>
		Heading
		<a href="{url}" class="link"><span class="material-symbols-outlined">link</span></a>
	</h1>
	```

*Icon* and *Link* type can be combined.

```html

```
